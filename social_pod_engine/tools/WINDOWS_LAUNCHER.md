# Inicio de Social Pod en Windows

1. La primera vez, hacé doble clic en `INSTALL_SOCIAL_POD.cmd` y esperá el mensaje de instalación completada.
2. Después, hacé doble clic en `START_SOCIAL_POD.cmd`.
3. Esperá a ver `Camoufox Profile Manager: ONLINE`.
4. Usá el menú `SOCIAL POD — X OPERATOR` que aparece en la misma ventana.
5. Al terminar, elegí `8. Salir` y cerrá la ventana. Camoufox queda abierto y listo para el próximo uso.

El inicio no activa publicaciones reales por sí mismo. Si `SOCIAL_POD_EXECUTION_ENABLED` no está configurada como `true`, el operador trabaja en modo `SAFE`.

Si querés cerrar Camoufox manualmente, cerrá la ventana o proceso de Camoufox Profile Manager que esté usando el puerto configurado (por defecto, `127.0.0.1:8000`).

## Acceso directo opcional

Hacé clic derecho sobre `START_SOCIAL_POD.cmd`, elegí **Mostrar más opciones** si aparece, y luego **Crear acceso directo**. Podés mover ese acceso directo al Escritorio.
